# Drum planning guidance

For drum requests, create musically plausible MIDI drum clips.

General MIDI drum pitches:
- Kick: 36
- Snare: 38
- Closed hi-hat: 42
- Pedal hi-hat: 44
- Open hi-hat: 46
- Low tom: 45
- Mid tom: 47
- High tom: 50
- Ride cymbal: 51
- Crash cymbal: 49

Jazz drum track:
- Prefer a ride pattern using pitch 51 on quarter notes and swung/off-beat 8ths where possible.
- Use pedal hi-hat on beats 2 and 4.
- Use light kick feathering on beats 1 and 3, with occasional syncopation.
- Use snare comping with varied velocities, not a rigid backbeat unless requested.
- Add fills every 8 or 16 bars using snare/toms/crash.
- Humanise with velocity variation and small timing variation when feasible.

Rock/pop/electronic drums:
- Use kick/snare/hi-hat foundations first.
- Add fills and crashes at section boundaries.
- Avoid over-dense note output.

If the user requests a full drum track but only Session clip tools are available, create a clip of the requested length when possible. Otherwise create a useful 8, 16, or 32 bar loop and explain the limitation.
