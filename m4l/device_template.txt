Max for Live device template (text)
----------------------------------

This is a step-by-step text template to build a Max-for-Live device that speaks to LLM-r via OSC.

Patch layout suggestions:

- `udpreceive 11000` -> receives UDP messages
- `route /llmr/state` -> if present, pass the JSON snapshot to a `js` parser to update state
- `route /live` -> pass to a `js` object that parses address and args and calls `live.path` / `live.object`
- `udpsend` or `udpsend` to send `/llmr/state` snapshots back to the server (optional)

Example message mapping (in your `js` object):

if address == "/live/device/set/parameter":
    use live.path/live.object to set device parameter
    send ack: {"ack":"/live/device/set/parameter","status":"ok","args":[...]} via udpsend

Notes:
- Use `live.observer` to emit state snapshots when parameters change.
- Filter incoming UDP by sender IP/port if you need to restrict access.
